Evolutionary Synthesis of Unified Activation Functions
This repository contains the Cartesian Genetic Programming (CGP) engine, generated RTL, functional-verification scripts, CNN evaluation code, and RI5CY processor-integration files for a unified hardware approximation of Swish, GELU, and Tanhexp activation functions.

All implementation files are located in the codes/ directory.

1. CGP Circuit Generation
codes/cgp_engine.cu
CUDA-accelerated CGP engine used to evolve a unified logic circuit for Swish, GELU, and Tanhexp. The selected CGP solution is automatically exported as synthesizable Verilog RTL.

Compile and run the CGP engine from the repository root:

nvcc -O3 codes/cgp_engine.cu -o codes/cgp_engine
./codes/cgp_engine
Alternatively, enter the codes/ directory first:

cd codes
nvcc -O3 cgp_engine.cu -o cgp_engine
./cgp_engine
The generated RTL is written to:

codes/unified_cuda_cgp_activation.v
The CGP engine periodically saves its evolutionary state. If a valid checkpoint file is present, execution resumes from the saved generation.

2. CGP-Generated RTL Verification
codes/unified_cuda_cgp_activation.v
Synthesizable Verilog RTL generated by the CGP engine. The design accepts a 16-bit fixed-point activation input and a function-selection input.

codes/tb_universal.v
Verilog testbench for simulating the generated activation circuit.

Compile and run the Verilog simulation using:

cd codes
iverilog -o sim_run.vvp tb_universal.v unified_cuda_cgp_activation.v
vvp sim_run.vvp
codes/cgp_act_fns_universal_tb.py
Python verification script used to compare the generated RTL outputs with the expected quantized activation values.

Run it from the repository root:

python3 codes/cgp_act_fns_universal_tb.py
The corresponding CGP and simulation results are stored in:

codes/cgp_results2.csv
codes/sim_results.csv
3. CNN Evaluation
The CNN experiments use quantization-aware training to compare the polynomial-based and CGP-generated activation approximations.

CIFAR-100
The relevant files are:

codes/train_cifar100_resnet.py
codes/run_cifar100_resnet.sh
Run all CIFAR-100 activation experiments using:

./codes/run_cifar100_resnet.sh

5. RI5CY Integration and Verification
Requirements
The RI5CY simulation flow requires:

Verilator 5.008
Other Verilator versions may not compile or execute the provided simulation flow correctly.

Check the installed version using:

verilator --version
The expected output should contain:

Verilator 5.008
codes/ri5cy_uni_act_fns_fixed.sv
RI5CY RTL containing the integrated unified activation-function hardware and custom instruction interface.

codes/ri5cy_unified_activation_sweep_tb.sv
SystemVerilog testbench used to test the supported activation functions and input values through the modified RI5CY core.

codes/run_ri5cy_activation_sweep.sh
Automates the complete RI5CY compilation and activation-function simulation flow.

Run it from the repository root using:

chmod +x codes/run_ri5cy_activation_sweep.sh
./codes/run_ri5cy_activation_sweep.sh
The script invokes Verilator, builds the simulation model, runs the activation sweep, and writes the results to:

codes/ri5cy_unified_activation_results.csv
The Verilator-generated build files are stored in:

codes/obj_dir/
codes/analyze_ri5cy_activation_csv.py
Analyzes the RI5CY activation-sweep results stored in the generated CSV file.

Run it using:

python3 codes/analyze_ri5cy_activation_csv.py
Typical Execution Flow
The complete workflow is:

1. Run the CUDA-based CGP engine.
2. Verify the generated Verilog RTL.
3. Run the CIFAR-100 and Tiny-ImageNet-200 CNN experiments.
4. Generate the training-loss plots.
5. Run the RI5CY activation sweep using Verilator 5.008.
6. Analyze the RI5CY simulation results.
Software Requirements
The workflow requires:

CUDA-compatible NVIDIA GPU
NVIDIA CUDA compiler (nvcc)
Python 3
PyTorch
TorchVision
Pandas
Matplotlib
Icarus Verilog
Verilator 5.008
Install the required Python packages using:

python3 -m pip install torch torchvision pandas matplotlib
On Ubuntu, Icarus Verilog can be installed using:

sudo apt install iverilog
Verilator must be installed separately at version 5.008 for the RI5CY simulation flow.
